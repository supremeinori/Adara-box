# Panduan Uji Manual — Modul M04: Open the File (Pembukaan Multi-Resource)

> **Tujuan:** Memverifikasi secara visual dan fungsional mode pemilihan resource (**Open the File**), peluncuran multi-resource melalui Windows Shell, penanganan error per item tanpa saling memblokir, ringkasan hasil peluncuran, pemisahan mode kelola vs buka, serta pembersihan pilihan sementara.  
> **Prasyarat:** Aplikasi telah di-build (`src/AdaraBox.App/bin/Release/net8.0-windows/AdaraBox.App.exe`).

---

## Persiapan Data Pengujian

Sebelum memulai, pastikan ada minimal 1 workspace (misal: "Uji M04") yang berisi kombinasi resource berikut:
1. **File Valid:** File teks `.txt` (contoh: `Dokumen.txt`).
2. **Folder Valid:** Sebuah folder (contoh: folder `Downloads` atau `Documents`).
3. **Tautan Web:** URL website (contoh: `https://github.com`).
4. **Aplikasi Valid:** Executable standar Windows (contoh: `C:\Windows\System32\notepad.exe`).
5. **Target Tidak Ada (Missing):** File yang sengaja dipindahkan/dihapus dari disk setelah ditambahkan ke workspace (misal: `Hilang.txt`).

---

## Skenario Pengujian

### Skenario 1: Toggle Mode "Open the File" dan Visual Akselerasi Header (FR-OF-01, NFR-UX-02)
1. Buka workspace "Uji M04".
2. Perhatikan tombol **"Open the File"** di header detail workspace sebelah tombol toggle Grid/List.
3. Klik tombol **"Open the File"**.
4. **Hasil yang diharapkan:**
   - Tombol aktif berubah warna aksen (hijau emerald gelap `#064E3B` dengan border `#10B981`).
   - Action bar Open the File muncul di bagian atas daftar resource.
   - Tombol aksi pengelolaan workspace ("Ganti Nama", "Hapus") di header detail disembunyikan.

---

### Skenario 2: Munculnya Checkbox pada Tampilan Grid dan List (FR-OF-02, FR-VW-05)
1. Saat mode Open the File aktif, periksa tampilan resource.
2. Beralih antara mode **Grid** dan **List** menggunakan toggle ⊞ Grid / ☰ List.
3. **Hasil yang diharapkan:**
   - Pada mode Grid: Checkbox muncul di sudut kiri atas setiap kartu resource.
   - Pada mode List: Checkbox muncul di kolom paling kiri setiap baris resource.
   - Mengganti tampilan tidak mengubah status checklist atau mereset mode.

---

### Skenario 3: Pemilihan Resource dan Counter Realtime (FR-OF-03, FR-OF-07, FR-OF-09)
1. Pastikan belum ada resource yang dicentang.
2. Perhatikan tombol **Open** di action bar: harus dalam kondisi **Disabled** (FR-OF-09), dan teks counter bertuliskan **"0 dipilih"**.
3. Klik salah satu kartu atau baris resource.
4. **Hasil yang diharapkan:**
   - Checkbox tercentang, kartu/baris mendapatkan border aksen hijau emerald `#10B981`.
   - Counter berubah menjadi **"1 dipilih"**.
   - Tombol **Open** menjadi aktif (Enabled).
5. Centang 2 resource lagi: counter menampilkan **"3 dipilih"**.

---

### Skenario 4: Tombol Bulk "Pilih Semua" dan "Bersihkan"
1. Di action bar, klik tombol **"Pilih Semua"**.
2. **Hasil yang diharapkan:** Semua resource dalam workspace langsung tercentang, counter menampilkan total seluruh resource (misal: "5 dipilih").
3. Klik tombol **"Bersihkan"**.
4. **Hasil yang diharapkan:** Semua checkbox tidak tercentang, counter kembali ke "0 dipilih", tombol Open kembali disabled.

---

### Skenario 5: Peringatan Pembukaan Banyak Item (> 10 Item) (FR-OF-10)
1. Tambahkan minimal 11 resource ke dalam satu workspace.
2. Aktifkan mode Open the File lalu klik **"Pilih Semua"** (atau centang manual 11 item).
3. **Hasil yang diharapkan:**
   - Banner peringatan warna kuning/amber muncul di action bar: *"⚠️ Membuka banyak resource sekaligus dapat membebani komputer."*
   - Tombol Open tetap dapat diklik (peringatan bersifat informatif dan tidak memblokir tindakan pengguna).

---

### Skenario 6: Pemisahan Mutlak Mode Kelola vs Mode Buka (FR-OF-05)
1. Saat mode Open the File aktif:
   - Tombol tambah resource (`+ File`, `+ Folder`, `+ Aplikasi`, `+ Tautan`) dan `⟳ Cek Ulang` di toolbar tersembunyi sepenuhnya.
   - Tombol aksi baris pada mode List (`▲`, `▼`, `✏`, `🗑`) tersembunyi sepenuhnya.
   - Klik kanan pada kartu/baris resource: context menu tidak muncul atau dinonaktifkan.
   - Klik kiri pada kartu atau baris: hanya mengubah status centang (toggle selection), tidak membuka editor nama/target.
2. **Hasil yang diharapkan:** Tidak ada kemungkinan pengguna salah memencet tombol hapus, edit, atau pengurutan saat memilih item untuk dibuka.

---

### Skenario 7: Pembersihan State Seleksi Sementara (FR-OF-08)
1. Centang 3 resource di mode Open the File.
2. Klik tombol **"Selesai"** di action bar (atau klik tombol **"Open the File"** di header).
3. Aktifkan kembali mode Open the File.
4. **Hasil yang diharapkan:** Semua centang telah bersih kembali ke 0 (state seleksi tidak disimpan permanen ke disk/database).
5. Centang 2 resource, lalu klik tombol **"← Kembali"** ke daftar workspace.
6. Masuk kembali ke workspace tersebut.
7. **Hasil yang diharapkan:** Workspace terbuka dalam mode normal (Manage mode), dan seleksi bersih.

---

### Skenario 8: Pembukaan Multi-Resource Sukses Beruntun (FR-OF-04, NFR-PF-03)
1. Masuk ke mode Open the File.
2. Centang kombinasi resource valid:
   - File `.txt`
   - Folder lokal
   - Tautan web (`https://...`)
   - Aplikasi (`notepad.exe`)
3. Klik tombol **Open**.
4. **Hasil yang diharapkan:**
   - Tombol Open menampilkan progres: `"Membuka (1/4)..."`, `"Membuka (2/4)..."`, dst. dengan jeda 150 ms antar item.
   - UI Adara Box tidak mengalami freeze / hang selama proses peluncuran berlangsung.
   - Notepad terbuka, browser default membuka URL, File Explorer membuka folder target, dan editor teks default membuka file `.txt`.
   - Panel ringkasan muncul: *"Semua resource (4 item) berhasil dibuka."*

---

### Skenario 9: Penanganan Kegagalan Per Item (FR-OF-06)
1. Masuk ke mode Open the File.
2. Centang 1 file yang valid dan 1 resource yang targetnya sengaja dihapus/hilang di disk (`Hilang.txt`).
3. Klik tombol **Open**.
4. **Hasil yang diharapkan:**
   - File yang valid **tetap berhasil terbuka** di aplikasi terkait.
   - Kegagalan file yang hilang **tidak menghentikan** proses pembukaan resource lain.
   - Aplikasi tidak crash dan tidak memunculkan exception teknis ke layar.
   - Panel ringkasan muncul dengan status: *"1 berhasil dibuka, 1 gagal."*
   - Di daftar kegagalan, tertera nama `Hilang.txt` dengan badge `"Tidak Ditemukan"` dan pesan penjelasan ramah: *"File tidak ditemukan di disk."*

---

### Skenario 10: Tombol "Coba Lagi yang Gagal"
1. Lanjutkan dari kondisi Skenario 9 (di mana 1 item gagal).
2. Kembalikan file `Hilang.txt` ke lokasi disk aslinya.
3. Di panel ringkasan, klik tombol **"Coba Lagi yang Gagal"**.
4. **Hasil yang diharapkan:**
   - Hanya item yang tadi gagal yang diluncurkan ulang.
   - File `Hilang.txt` berhasil terbuka.
   - Panel ringkasan diperbarui menampilkan semua berhasil.

---

### Skenario 11: Navigasi Keyboard
1. Masuk ke mode Open the File.
2. Tekan `Ctrl+A`: Seluruh resource langsung terpilih.
3. Tekan `Enter`: Meluncurkan pembukaan resource yang terpilih.
4. Pada panel ringkasan yang muncul, tekan tombol `Esc`: Panel ringkasan tertutup.
5. Tekan tombol `Esc` lagi: Keluar dari mode Open the File kembali ke mode kelola biasa.
6. Arahkan fokus ke salah satu kartu menggunakan keyboard `Tab` lalu tekan tombol `Space`: Checkbox kartu tersebut berganti status (terpilih/tidak).

## Verifikasi Integritas & Keamanan

- [ ] **Aturan Emas #1 (Reference, not copy):** Menghapus resource dari workspace tidak pernah menghapus file fisik di Windows Explorer.
- [ ] **Aturan Emas #3 (Tidak ada shell execution):** Pembukaan murni menggunakan `ProcessStartInfo` Windows ShellExecute langsung tanpa `cmd /c` atau `powershell`.
- [ ] **NFR-SC-04 (Privasi Log):** Log aplikasi di `%LOCALAPPDATA%\AdaraBox\logs` mencatat tipe resource dan status hasil peluncuran (Information level), tanpa mencatat path lengkap pengguna di level Information.
