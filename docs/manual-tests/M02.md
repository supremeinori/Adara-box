# Manual Smoke Test Guide — Modul M02 (Workspace Management & Persistensi)

**Target:** Memverifikasi fungsionalitas persistensi SQLite, migrasi skema, preferensi visibilitas top bar, dan alur CRUD Workspace secara manual.  
**Executable:** `src/AdaraBox.App/bin/Release/net8.0-windows/AdaraBox.App.exe`  
**Database Path:** `%LOCALAPPDATA%\AdaraBox\adarabox.db`

---

## Skenario Uji

| # | Langkah Uji | Tindakan Pengguna | Hasil yang Diharapkan | Status |
|---|---|---|---|---|
| **1** | **Migrasi Database Awal** | Jalankan `AdaraBox.App.exe` pada environment bersih (atau hapus `%LOCALAPPDATA%\AdaraBox\adarabox.db` sebelumnya). | Aplikasi berjalan normal tanpa error; file `%LOCALAPPDATA%\AdaraBox\adarabox.db` dibuat secara otomatis dengan WAL mode dan tabel `workspace`, `resource`, `settings` terbuat (`PRAGMA user_version = 1`). | [HUMAN CHECK] |
| **2** | **Empty State & Data-driven Add Workspace** | Buka panel Workspace atau amati sisi kanan header top bar. | Muncul tombol cepat data-driven **"+ Workspace"** di top bar; panel menampilkan state kosong: *"Belum ada workspace. Buat workspace pertamamu untuk mulai mengelompokkan file, aplikasi, dan tautan."* beserta tombol *"Buat Workspace"*. | [HUMAN CHECK] |
| **3** | **Validasi Form Pembuatan Workspace** | 1. Klik tombol **"+ Workspace"**.<br>2. Kosongkan input dan tekan `Enter` atau klik Simpan.<br>3. Ketik spasi saja lalu Enter.<br>4. Ketik > 60 karakter. | 1. Muncul form inline dengan field nama workspace terfokus otomatis.<br>2. Muncul pesan error di bawah field: *"Nama workspace tidak boleh kosong."* (tidak memakai MessageBox).<br>3. Pesan error tetap muncul.<br>4. Field dibatasi maks 60 karakter / pesan error *"Nama workspace maksimal 60 karakter."*. | [HUMAN CHECK] |
| **4** | **Membuat Workspace & Masuk ke Detail View** | 1. Masukkan nama `"Carry On"` lalu tekan `Enter`. | Form tertutup, workspace tersimpan ke SQLite, dan aplikasi otomatis membuka **tampilan detail workspace** `"Carry On"` dengan tombol *"← Kembali"* serta placeholder jujur: *"Resource untuk workspace ini belum ada. Pengelolaan file, folder, aplikasi, dan tautan akan hadir di Modul M03."*. | [HUMAN CHECK] |
| **5** | **Duplikat Nama Diizinkan (FR-WS-07)** | Buat workspace kedua dengan nama yang sama: `"Carry On"`. | Pembuatan berhasil; kedua workspace `"Carry On"` muncul di daftar dengan ID internal yang unik. | [HUMAN CHECK] |
| **6** | **Ganti Nama Workspace** | Klik tombol pensil (✏) pada kartu workspace atau dari menu konteks (klik kanan -> *"Ganti Nama"*), ubah nama menjadi `"Carry On Project"`, tekan `Enter`. | Form ganti nama tampil dengan nama lama terisi; setelah disimpan, nama pada kartu langsung terbarui menjadi `"Carry On Project"`. | [HUMAN CHECK] |
| **7** | **Hapus Workspace dengan Dialog Konfirmasi** | Klik tombol tong sampah (🗑) atau dari menu konteks -> *"Hapus"*. | Muncul kotak dialog konfirmasi bertuliskan:<br>• Nama workspace.<br>• Jumlah resource (0 resource).<br>• Peringatan tegas: *"Hanya menghapus workspace dari Adara Box. File, folder, aplikasi, dan tautan aslinya tidak terpengaruh."*<br>Jika klik Batal/No: tidak dihapus.<br>Jika klik Ya/Yes: baris workspace dihapus dari database dan kartu hilang dari tampilan UI. | [HUMAN CHECK] |
| **8** | **Persistensi Workspace & Preferensi Hide setelah Restart** | 1. Buat workspace `"College"` dan `"Reading"`.<br>2. Di menu Pengaturan, aktifkan *"Sembunyikan top bar otomatis"*.<br>3. Aplikasi langsung mulai dalam mode tersembunyi (strip pemicu aktif, preferensi Hide tersimpan di SQLite).<br>2.
