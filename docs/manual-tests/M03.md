# Manual Smoke Test Guide — Modul M03 (Resource Management & Tampilan Grid/List)

**Target:** Memverifikasi fungsionalitas penambahan, pengeditan, penghapusan referensi resource (file, folder, aplikasi, tautan), pemeriksaan ketersediaan latar belakang, dan pengalihan tampilan Grid/List secara manual.  
**Executable:** `src/AdaraBox.App/bin/Release/net8.0-windows/AdaraBox.App.exe`

---

## Skenario Uji

| # | Langkah Uji | Tindakan Pengguna | Hasil yang Diharapkan | Status |
|---|---|---|---|---|
| **1** | **Detail Workspace & State Kosong Resource** | Buka top bar -> klik *"Workspace"* -> buat atau pilih workspace. | Aplikasi membuka tampilan detail workspace dengan judul workspace, tombol *"← Kembali"*, tombol toggle viewmode *"⊞ Grid / ☰ List"*, dan state kosong: *"Workspace ini masih kosong. Tambahkan file, folder, aplikasi, atau tautan pertama Anda ke dalam workspace ini."* | [HUMAN CHECK] |
| **2** | **Menambah File (Multiselect)** | Klik tombol **"+ File"**, pilih 2 atau lebih file (misal file dokumen atau gambar). | Dialog pemilihan file muncul; setelah memilih file, semua file muncul di koleksi workspace dalam satu batch; ikon file diekstrak dengan tepat. | [HUMAN CHECK] |
| **3** | **Menambah Folder** | Klik tombol **"+ Folder"**, pilih satu folder lokal. | Dialog folder picker muncul; folder berhasil ditambahkan dengan ikon folder dan nama folder yang sesuai. | [HUMAN CHECK] |
| **4** | **Menambah Aplikasi** | Klik tombol **"+ Aplikasi"**, pilih shortcut `.lnk` atau file `.exe`. | Dialog file picker dengan filter aplikasi muncul; aplikasi tertambahkan dengan ikon aslinya. | [HUMAN CHECK] |
| **5** | **Menambah Tautan (Normalisasi & Validasi)** | 1. Klik **"+ Tautan"**.<br>2. Masukkan URL tanpa skema: `github.com`.<br>3. Coba masukkan URL berbahaya: `javascript:alert(1)`. | 1. | **6** | **Toggle Tampilan Grid & List (FR-VW-01…05)** | 1. Klik tombol **"☰ List"** di header.<br>2. Amati daftar resource.<br>3. Klik tombol **"⊞ Grid"**.<br>4. Restart aplikasi. | 1. Tampilan berganti ke baris satu per satu (List) secara instan tanpa reload database atau kehilangan data.<br>2. Menampilkan ikon kecil, nama, jenis tag, dan info pembeda path.<br>3. | **7** | **Edit Resource** | Klik tombol pensil (✏) atau klik kanan item -> pilih *"Edit"*, ubah nama tampilan dan target, tekan Simpan. | Form edit menampilkan nama dan target terisi; tipe resource terkunci; setelah disimpan, informasi kartu langsung terbarui. | [HUMAN CHECK] |
| **8** | **Pengurutan Manual (Move Up/Down)** | Klik tombol ▲ (Pindah ke Atas) atau ▼ (Pindah ke Bawah) pada salah satu item di tampilan List atau via context menu. | Urutan item bertukar posisi dan urutan baru langsung tersimpan ke database. | [HUMAN CHECK] |
