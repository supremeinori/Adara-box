# Panduan Uji Manual — Modul M05: MVP Hardening

> **Tujuan:** Memverifikasi ketahanan runtime, penanganan database korup dan pemulihan, shortcut global, opsi auto-start Windows, kompatibilitas multi-monitor & DPI, serta aksesibilitas navigasi keyboard.  
> **Prasyarat:** Binary release telah di-build (`src/AdaraBox.App/bin/Release/net8.0-windows/AdaraBox.App.exe`).

---

## Skenario Pengujian

### Skenario 1: Penanganan Database Korup & Dialog Pemulihan (FR-CF-03, NFR-RL)
1. Tutup aplikasi Adara Box jika sedang berjalan.
2. Buka direktori data `%LOCALAPPDATA%\AdaraBox`.
3. Buat backup database `adarabox.db` ke tempat aman, lalu ubah isi file `adarabox.db` menjadi byte sembarang (contoh: buka di Notepad dan ketik teks acak lalu simpan).
4. Jalankan `AdaraBox.App.exe`.
5. **Hasil yang diharapkan:**
   - Aplikasi mendeteksi integritas rusak (`PRAGMA quick_check` gagal).
   - Jendela **Pemulihan Database (Database Recovery Window)** muncul dengan pesan jelas.
   - Tersedia tombol:
     - **Buka Folder Data**: Membuka Windows Explorer ke `%LOCALAPPDATA%\AdaraBox`.
     - **Pulihkan dari Backup**: Menampilkan daftar backup jika tersedia. File korup otomatis diarsipkan menjadi `adarabox.db.corrupt-{timestamp}` (tidak dihapus).
     - **Mulai dengan Database Baru**: Mengarsipkan database korup dan membuat schema baru yang bersih.
     - **Keluar**: Menutup aplikasi tanpa merusak file data.

---

### Skenario 2: Deteksi Database Versi Lebih Baru
1. Tutup aplikasi Adara Box.
2. Buka database `adarabox.db` menggunakan SQLite CLI/browser dan ubah `PRAGMA user_version = 999;`.
3. Jalankan `AdaraBox.App.exe`.
4. **Hasil yang diharapkan:**
   - Dialog pemulihan muncul dan menampilkan pesan bahwa database dibuat oleh versi aplikasi yang lebih baru.
   - Skema database lama tidak diubah secara sembarangan.

---

### Skenario 3: Multi-Monitor & DPI (NFR-CP-03, SRS §16 no. 2)
1. Hubungkan 2 monitor ke sistem (atau konfigurasikan skala DPI berbeda, misal 100% dan 125%/150%).
2. Gerakkan kursor ke Monitor 2.
3. Tekan shortcut global `Ctrl+Alt+Space` atau arahkan kursor ke area atas layar monitor 2.
4. **Hasil yang diharapkan:**
   - Top bar muncul di bagian tengah atas Monitor 2 (monitor tempat kursor berada), bukan terlempar ke Monitor 1.
   - Dimensi, font, dan jarak antar tombol tampil proporsional sesuai DPI monitor yang bersangkutan (PerMonitorV2).
   - Ubah resolusi layar atau cabut salah satu monitor: Top bar langsung mereposisi diri dan tidak berada di luar layar.

---

### Skenario 4: Shortcut Global Top Bar (FR-TB-06)
1. Buka modul **Pengaturan (Settings)** pada top bar.
2. Periksa input **Global Shortcut**: nilai bawaan adalah `Ctrl+Alt+Space`.
3. Minimalkan atau fokus ke aplikasi lain (misal: Browser atau Notepad).
4. Tekan `Ctrl+Alt+Space`.
5. **Hasil yang diharapkan:**
   - Top bar Adara Box langsung muncul dan menerima fokus.
6. Coba ubah shortcut menjadi kombinasi tidak valid (misal: hanya menekan `Space` atau `Ctrl+Alt+Delete`):
   - Muncul pesan validasi kesalahan di Settings.
7. Ubah shortcut menjadi `Ctrl+Shift+B` lalu klik **Simpan Shortcut**:
   - Shortcut berhasil didaftarkan dan dapat digunakan untuk memanggil top bar.

---

### Skenario 5: Startup Bersama Windows (FR-CF-04)
1. Buka modul **Pengaturan (Settings)**.
2. Periksa sakelar **Jalankan saat Windows mulai**. Nilai bawaan harus **Mati (OFF)**.
3. Klik untuk mengaktifkan (ON).
4. Buka Registry Editor (`regedit.exe`) dan periksa kunci `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
5. **Hasil yang diharapkan:**
   - Terdapat entri bernama `AdaraBox` yang menunjuk ke executable aplikasi.
   - Matikan sakelar: entri `AdaraBox` dihapus secara bersih dari registry.

---

### Skenario 6: Aksesibilitas Navigasi Keyboard Penuh (NFR-UX-03)
1. Munculkan top bar dengan tombol Tab atau shortcut `Ctrl+Alt+Space`.
2. Gunakan `Tab` untuk berpindah antar modul, tekan `Enter` pada Workspace: Panel Workspace terbuka.
3. Pada daftar workspace, gunakan panah / Tab untuk memilih kartu workspace:
   - Tekan `F2`: Form inline ganti nama workspace langsung terbuka dan teks terpilih.
   - Tekan `Esc`: Form batal dan kembali ke kartu workspace.
   - Tekan `Enter`: Masuk ke detail workspace.
4. Di dalam detail workspace:
   - Gunakan `Tab` untuk fokus pada kartu resource.
   - Tekan `F2`: Form inline edit resource terbuka.
   - Tekan `Esc`: Form batal.
   - Tekan `Delete`: Dialog konfirmasi hapus resource dari workspace muncul.
5. Aktifkan mode Open the File:
   - Tekan `Space` pada kartu resource: Checkbox tercentang / tidak tercentang.
   - Tekan `Ctrl+A`: Seluruh resource tercentang.
   - Tekan `Enter`: Membuka resource yang terpilih.
6. Tekan `Esc` berulang kali:
   - Mundur dari form -> mundur dari Open mode -> mundur dari detail workspace -> menutup panel top bar.
